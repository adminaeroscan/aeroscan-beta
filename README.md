# AeroScan AI - Beta

Beta Release (Tester Version) of the AeroScan AI desktop app for Windows 10/11 (64-bit).

**Download:** see [Releases](../../releases/latest), or https://ai.aeroscan.co.za/download

- `...Beta-Setup-...exe` - installer
- `...Beta-Portable-...exe` - no install needed

The first 20 people to register in the app get free Tester access. The beta is not code-signed yet, so Windows SmartScreen may warn: click **More info**, then **Run anyway**.

This repository contains release binaries only. Report problems through the Issues tab.
