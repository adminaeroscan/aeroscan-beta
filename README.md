### GET STARTED
## Up and running in two minutes

1. **Download and run.** If Windows SmartScreen warns, click **More info**, then **Run anyway**.
2. **Register with your email**, in the app or on the [website](https://ai.aeroscan.co.za/account). Confirm the link we email you, then sign in. It is free for everyone.
3. **Pick a model and go.** Choose a default model with its cost shown, then chat, or point the agent at a project folder.

### WHAT YOU GET
## Everything in one window

No browser tabs, no copy-pasting code. Work happens on your own machine, in your own folders.

#### Agent mode: an agent that works in your project

Give it a task and it plans, edits files, runs your tests and reports back.

- ✅ Reads, writes and builds in a folder you choose
- ✅ Review, undo or commit every change it makes
- ✅ Stops when the checks pass, so it doesn't waste requests

<img src="docs/agent-chat.webp" alt="Agent mode after a finished task: what it changed, the files, the cost, and the live preview beside the chat" width="100%">

#### Spec mode: plan it first, then build it task by task

Describe a feature and get requirements, a design and a task list. Then build the tasks one at a time, or all of them, and watch each one tick off with its files, cost and commit.

- ✅ Requirements, design and tasks you can read and edit
- ✅ Every task shows its changed files, time, requests and commit
- ✅ Review the changes of any task, or build the rest in one go

<img src="docs/agent-spec.webp" alt="Spec mode: eight finished task cards showing their changed files, time, requests and commits" width="100%">

#### Live preview: point at the part you want changed

The agent reloads your running app as it works. Use Point & change to click any part of it, say what should be different, and send it to the agent. Electron apps open in their own window too.

- ✅ Click an element, then describe the change in words
- ✅ Full, tablet and phone sizes
- ✅ The preview reloads when the agent changes files

<img src="docs/app-preview.webp" alt="The agent preview of a spreadsheet app with Point and change: a picked ribbon panel and a box to say what should change" width="100%">

#### Design mode: build a website and watch it appear

Describe a site, or plan it with the wizard, and see it written live. Click any part of the page to change just that part, restyle the whole site, and export it when you are happy.

- ✅ Pages, sections, your own images and a style panel
- ✅ History you can restore, and a check for broken links
- ✅ Desktop, tablet and phone previews

<img src="docs/design.webp" alt="Design mode: a cinematic gaming-PC landing page built live, with the chat on the left and the page on the right" width="100%">

A widget for another monitor shows what the agent is doing, how far it has got and what it is waiting for. It works in portrait on a 1080p screen and in landscape on a 1440p one, and you can answer the agent from it.

- ✅ Live progress, checks and a clock
- ✅ Approve a step or type a reply from the widget
- ✅ Portrait, landscape, mini and full screen

Models are added and retired all the time, so the full list (chat models, the ones that can work in agent mode, and the image models, with their costs) lives on the website where it is always current:

### VERIFY
## Check your download

The beta isn't code-signed yet, which is why Windows shows a warning. To make sure the file is exactly ours, compare its SHA-256 hash with the one in the [release notes](https://github.com/adminaeroscan/aeroscan-beta/releases/latest):

```powershell
Get-FileHash "$env:USERPROFILE\Downloads\AeroScan.AI-Beta-Setup-1.0.0-beta.10-x64.exe" -Algorithm SHA256
```

### FAQ
## Questions

<details><summary><b>Is it free?</b></summary><br>Yes, for everyone. The Free plan gives you every model with fair daily limits, and models marked Free never use a request. Donators get a much larger daily allowance. The current limits are on the [website](https://ai.aeroscan.co.za/#plan).</details>
<details><summary><b>Why does Windows say it "protected your PC"?</b></summary><br>The beta isn't code-signed yet, and SmartScreen warns about new unsigned apps. Click <b>More info</b>, then <b>Run anyway</b>. To be sure, check the file's hash as shown above.</details>
<details><summary><b>What counts as a request?</b></summary><br>Each chat message uses the request cost of the model you picked; free models use none. In agent mode, every step the agent takes uses the model's cost. A picture uses the cost of its image model.</details>
<details><summary><b>Where do my files go?</b></summary><br>The agent only works in the project folder you choose, on your own PC. You review its changes and can undo them.</details>
<details><summary><b>Is the source code available?</b></summary><br>Not at the moment. This repository holds release builds only.</details>
<details><summary><b>Where do I get help or report a bug?</b></summary><br>Join our <a href="https://discord.gg/DWYhRmu9Dz">Discord</a>: testers get their own channels for bug reports, feature requests and agent mode. You can also open an issue here on GitHub.</details>
<details><summary><b>Can I use it in VS Code?</b></summary><br>Yes. In the app, open Settings → Integrations and click <b>Add to VS Code</b> (or <b>Update</b>). Your models, plus "AeroScan Agent" versions of the agent models, appear in Copilot Chat's model picker. Paste your API key once when VS Code asks. Keep the app open while you use the AeroScan Agent models.</details>
<details><summary><b>Mac or Linux?</b></summary><br>Windows 10 and 11 (64-bit) only for now.</details>
